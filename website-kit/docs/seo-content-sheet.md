# SEO Content Sheet

One row per page. Fill this in with the client before writing copy. It drives
page content, metadata, and the `content/pages.json` for the site.

## Columns

| Column | Meaning |
| --- | --- |
| **Page** | Page slug / URL path (e.g. `/`, `/services/x`, `/contact`). |
| **Audience** | Who this page is for (persona, segment). |
| **Key message** | The single most important thing this page must land. |
| **Services** | Which service(s) this page covers. |
| **Location** | Target geography for local search (city/region), if any. |
| **Search intent** | What the visitor is trying to do (informational / commercial / transactional) + primary keyword. |
| **Proof** | Evidence that builds trust (case study, review, certification, stat). |
| **CTA** | The primary call to action on the page. |
| **Required company info** | Legally/operationally required details to show (company no., address, VAT, contact). |
